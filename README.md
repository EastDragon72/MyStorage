# MyStorage

React + TypeScript + Vite 기반의 모바일 우선 PWA 기본 프로젝트입니다. MyStorage의 첫 화면과 PWA 기본 설정만 포함합니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 빌드

```bash
pnpm check
pnpm build
```

## 현재 단계 범위

이번 단계에는 MyStorage 기본 화면, 반응형 모바일 우선 스타일, PWA manifest, Service Worker, 앱 아이콘과 실행 설정만 포함되어 있습니다.

다음 항목은 아직 구현하지 않았습니다.

- GitHub 연결
- Supabase 연결
- 로그인/Auth
- AI 기능
- Vector/Embedding
- 검색 기능
- Notes/Memories CRUD
